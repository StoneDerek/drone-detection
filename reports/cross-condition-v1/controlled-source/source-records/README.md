# UAV Acoustic Dataset v1.1.0: data and experiments

Creators: Huilong Wang, Peng Chen, Zhimin Chen, and Yuye Liu. Affiliations and preferred citation are in `CITATION.cff`. License: CC BY 4.0.

## Contents

- `dataset/`: 273 synchronized physical recordings, comprising 200 hovering DJI Flip UAV recordings, 28 field background recordings, and 45 controlled loudspeaker re-recordings of non-UAV sounds. The 4,368 mono WAV files are 48 kHz, 16-bit PCM and total 7.221 hours when each physical recording is counted once.
- `dataset/metadata/`: recording/file/session/condition indexes, source identifiers, microphone coordinates, and grouping fields.
- `validation/`: file, annotation, waveform, delay and spatial validation code and archived results. `validation/calibration/sweep_a0_4m/` adds the separate original 16-channel sweep as lossless PCM WAV files; it is not part of the 273-recording dataset.
- `experiments/source/`: archived experiment implementations.
- `experiments/support/`: the existing feature-extraction and residual CNN modules required by the experiments.
- `experiments/results/`: four archived official runs from 13–14 October 2026. Predictions, fold assignments, configurations, summaries, training histories and plotting data are included. Trained model weights and feature caches are regenerated by the scripts.
- `reproduce.py`: portable entry point that locates the extracted dataset and support modules. New results are written to `reproduction_outputs/`.

## Data use

Each recording has 16 separate channels and a JSON metadata document. Channels 0–7 lie along x and 8–15 along y, with 42.5 mm adjacent spacing and no microphone at the center. The acquisition azimuths A0/A1/A2/A3 correspond to 180/90/0/−90 degrees. Positions are nominal coordinates derived from the prescribed acquisition conditions.

Keep all channels and segments from a physical recording in one split. Detection folds group acquisition dates and negative-sample sources/categories. Azimuth folds group repeated nominal spatial conditions. Detection uses split seed 42 with training seeds 42, 123, and 2026 sharing the same four folds. Azimuth classification generates a separate nominal-condition-grouped partition for each base seed (42, 123, 2026); within a base seed, all representations, subsets and perturbations share the folds, and the classifier seed is the base seed plus the fold index. Exact reported folds are retained in the archived prediction and split files; recommended metadata splits do not replace these experiment-specific assignments.

Controlled replay recordings are identified separately from field background. Their source excerpts were selected from FSD50K material licensed under CC0 1.0; the original identifiers are retained in the JSON provenance. The release does not include the source RAW files or the original FSD50K corpus.

## Validation

From `dataset/`, run `python scripts/audit_release.py --root .` to check all audio hashes and metadata. Python 3.10 or newer is sufficient for this audit; no third-party packages are needed. The command writes a fresh audit report. Use `--no-hash` for a structural check.

## Reproduce the experiments

Use a Python environment with the dependencies in `requirements.txt`. The archived `environment.json` and run manifests retain the original software settings. From the extracted archive root:

```text
python "validation/代码/04b_sweep_calibration.py"
python reproduce.py detection --preflight-only
python reproduce.py negative --preflight-only
python reproduce.py azimuth --preflight-only
python reproduce.py detection
python reproduce.py negative
python reproduce.py azimuth
python reproduce.py distance
```

The standalone detection command does not require the optional power-fusion baseline summary or comparison table. The detection command extracts the original 16 × 40 × 256 MFCC inputs, runs the seed-42 full-channel model, and then runs the remaining channel/seed comparisons: four folds and three seeds per input, 36 models in total. The negative command compares the original spectral/IPD detection conditions, including training with and without controlled-replay negatives. The azimuth command runs the original spatial input, channel-count and perturbation experiments. The distance run is an archived supplementary analysis; it is not a new result added to the associated JAES manuscript.

`--dataset PATH` and `--output PATH` override the dataset and new-output directories. The historical Chinese one-click scripts are retained for provenance; `reproduce.py` supplies portable paths without rebuilding the dataset from unavailable RAW sources.

## Maintenance revision 2026-11-09

The primary dataset remains version 1.1.0: all 273 recording JSON documents, all 4,368 main WAV files, and all archived experiment predictions and results are unchanged. This maintenance revision synchronizes citation details with the repository record, fixes the standalone CNN export dependency, and adds the missing sweep input plus a portable calibration command. The original 32-channel capture included unused/non-acoustic channels 16-31; only acoustic channels 0-15 are supplied and analyzed. The calibration supplement adds one synchronized recording stored as 16 WAV files (79.658666667 s); it is excluded from the main dataset counts and 7.221-hour duration.

The repository owner controls file visibility. If access is restricted during peer review, reviewers need a working read-only sharing link from the owner. The DOI identifies the deposited record; it does not by itself guarantee anonymous access to restricted files.
